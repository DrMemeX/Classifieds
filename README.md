# Classifieds



Classifieds — платформа частных объявлений, предназначенная для размещения и поиска предложений, а также взаимодействия покупателей и продавцов.



## Функциональные требования



### Пользователь (`USER`)



Пользователь может:



- регистрироваться и выполнять авторизацию;

- просматривать и редактировать собственный профиль;

- просматривать объявления;

- выполнять поиск и фильтрацию объявлений;

- просматривать публичную информацию о продавцах;

- создавать, редактировать и удалять собственные объявления;

- загружать изображения объявлений и изменять порядок их отображения;

- оставлять и удалять собственные комментарии;

- создавать диалоги по объявлениям;

- просматривать историю переписки;

- обмениваться сообщениями с другими пользователями.



### Администратор (`ADMIN`)



Администратор может:



- просматривать информацию о пользователях и объявлениях;

- блокировать и разблокировать пользователей;

- блокировать объявления;

- удалять комментарии в рамках модерации.



Администратор не может создавать других администраторов и управлять категориями.



### Суперадминистратор (`SUPER\_ADMIN`)



Суперадминистратор имеет возможности администратора, а также может:



- создавать учётные записи администраторов;

- создавать и изменять категории;

- активировать и деактивировать категории.



Создание других учётных записей `SUPER\_ADMIN` через API не допускается.

## Основные сущности


### User



Системная учётная запись пользователя.



Содержит данные, необходимые для аутентификации, авторизации и определения состояния аккаунта.



Поддерживаемые роли:

- `USER`

- `ADMIN`

- `SUPER\_ADMIN`



Основные статусы:

- `ACTIVE`

- `BLOCKED`

- `DELETED`



### UserProfile



Публичный профиль пользователя.



Содержит персональную информацию, доступную другим пользователям: имя, фамилию и номер телефона.



Связан с `User` отношением один к одному.



### Category



Категория объявления.



Категории имеют иерархическую структуру и могут содержать родительские и дочерние категории.



Используются для группировки и фильтрации объявлений.



### Region



Регион размещения объявления.



Используется при создании объявления, поиске и фильтрации.



Одному региону может соответствовать множество объявлений.



### Advertisement



Основная сущность объявления.



Содержит продавца, категорию, регион, населённый пункт, название, описание, цену и текущий статус.



Основные статусы:



- `ACTIVE`

- `INACTIVE`

- `BLOCKED`

- `DELETED`



### AdvertisementImage



Изображение объявления.



В базе данных хранится ссылка или ключ файла и порядок его отображения.



Одно объявление может содержать несколько изображений.



### Comment



Комментарий пользователя под объявлением.



Комментарий связан с объявлением и своим автором.



Пользователь может удалять собственные комментарии, а административные пользователи могут удалять их в рамках модерации.



### Conversation



Диалог между покупателем и продавцом, связанный с конкретным объявлением.



Для одной пары «покупатель — объявление» может существовать только один диалог.



### Message



Отдельное сообщение внутри диалога.



Сообщение связано с диалогом и автором. История сообщений сохраняется и отображается в порядке отправки.
